Glow Curl App

Descripción

Glow Curl App es una aplicación web desarrollada como proyecto formativo del programa Análisis y Desarrollo de Software (ADSO) del SENA.

Está diseñada para apoyar el cuidado del cabello ondulado, rizado y afro, ofreciendo a los usuarios un espacio donde pueden consultar productos, conocer servicios capilares, gestionar sus citas y organizar sus compras mediante una interfaz intuitiva y adaptable a diferentes dispositivos.

Objetivo

Desarrollar una aplicación web que facilite el acceso a productos y servicios para el cuidado capilar, permitiendo a los clientes gestionar su perfil, consultar sus citas y organizar sus compras de manera sencilla.

Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- MySQL (para la gestión de datos, según la implementación del proyecto)
- Git
- GitHub

Funcionalidades

Módulo Cliente

- Inicio: presenta información general y accesos a las secciones de la aplicación.
- Registro e inicio de sesión: permite crear una cuenta y acceder a la aplicación.
- Perfil: permite consultar y actualizar la información personal y capilar.
- Productos: permite explorar el catálogo de productos disponibles.
- Servicios: permite consultar los servicios capilares ofrecidos.
- Citas: permite gestionar las reservas y consultar las citas.
- Carrito: permite agregar productos, modificar cantidades y consultar el total.
- Compras: permite consultar los productos adquiridos y sus valores.
- Historial: permite revisar los registros de compras.
- Sobre nosotros: presenta información general del proyecto.

Diseño adaptable

La aplicación cuenta con una interfaz diseñada para adaptarse a computadores, tabletas y celulares, incluyendo un menú de navegación para dispositivos móviles.

Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar el proyecto utilizando Live Server o un servidor local.
4. Abrir `index.html` desde el navegador.

Nota:Si se utiliza la conexión con MySQL, también será necesario iniciar el servidor backend y configurar la base de datos.
